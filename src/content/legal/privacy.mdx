## 2. Hosting und Bereitstellung

Diese Website wird über Vercel bereitgestellt. Beim Aufruf der Website verarbeitet Vercel technische Verbindungsdaten, darunter IP-Adresse, Zeitstempel und angeforderte URL, um die Website auszuliefern und den Betrieb zu sichern. Weitere Informationen finden Sie in der [Datenschutzerklärung von Vercel](https://vercel.com/legal/privacy-policy).

Cloudflare wird für die DNS-Verwaltung der Domain eingesetzt. Dabei können technische Verbindungsdaten verarbeitet werden, wenn Anfragen über Cloudflare-Dienste geleitet werden. Einzelheiten hängen von der jeweiligen DNS- und Proxy-Konfiguration ab. Informationen dazu finden Sie in der [Datenschutzerklärung von Cloudflare](https://www.cloudflare.com/privacypolicy/).

## 3. Vercel Analytics und Speed Insights

Wir verwenden Vercel Analytics zur Auswertung von Seitenaufrufen sowie Vercel Speed Insights zur Messung technischer Leistungswerte wie Web Vitals. Laut Vercel verwendet Analytics keine Cookies und speichert anonymisierte Daten. Speed Insights erfasst unter anderem Route, Browser, Gerätetyp, Betriebssystem und Leistungswerte. Die Daten werden an Vercel übermittelt. Weitere Informationen: [Vercel Analytics](https://vercel.com/docs/analytics) und [Speed Insights: Datenschutz](https://vercel.com/docs/speed-insights/privacy-policy).

## 4. GitHub-API

Auf der Website werden zusammengefasste Kennzahlen der GitHub-Organisationen HMLabs und HML Gaming angezeigt. Die Website ruft dazu serverseitig Repository-Metadaten und Commit-Zahlen über die GitHub-API ab und speichert die Ergebnisse zeitweise zwischen. Ein konfigurierter GitHub-Token kann auch private, für diesen Token zugängliche Repositories einbeziehen. Angezeigt werden nur Summen; Repository-Namen und Inhalte privater Repositories werden nicht auf der Website veröffentlicht. Beim Besuch dieser Website stellt Ihr Browser keine direkte Verbindung zur GitHub-API her. Bei den API-Anfragen verarbeitet GitHub technische Daten des Servers.

## 5. Einstellungen im Browser

Die Auswahl des Hell- oder Dunkelmodus wird in Ihrem Browser im localStorage gespeichert. Diese Einstellung wird nicht an den Server übermittelt. Die Website setzt dafür keine Cookies.

## 6. Schriftarten

Die Schriftarten werden mit `next/font` in die Website eingebunden. Beim normalen Aufruf der Website wird deshalb keine Verbindung zu Google Fonts hergestellt.
